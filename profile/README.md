# TongjiCEIENotes

这里是同济大学电子与信息工程学院学业发展中心维护的学科笔记整理项目。

本组织用于集中整理、维护和发布电子与信息工程学院开设课程的学习笔记、复习资料，方便同学们查阅、学习，同时也开源了对应 LaTeX 源码，方便学协内部成员的协作与广大读者同学提出建议并持续完善。

## 使用说明

各课程仓库包含：

- `main.tex`：笔记主文件
- `figures/`：图片与水印等资源
- 样式文件：用于统一排版

如需阅读 PDF笔记，请优先查看对应仓库的 Release
