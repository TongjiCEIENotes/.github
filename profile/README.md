# TongjiCEIENotes

这里是同济大学电子与信息工程学院学业发展中心维护的学科笔记整理项目。

本组织用于集中整理、维护和发布电子与信息工程学院相关课程的学习笔记、复习资料与配套 LaTeX 源码，方便同学们查阅、学习、协作与持续完善。

## 项目定位

- 面向同济大学电子与信息工程学院相关课程的学习资料整理
- 以 LaTeX 源码和可编译文档为主要维护形式
- 尽量保持内容结构清晰、排版统一、来源透明
- 鼓励同学们基于课程学习经验参与补充与修订

## 已整理课程

- [复变函数与积分变换](https://github.com/TongjiCEIENotes/Functions-of-a-Complex-Variable-and-Integral-Transforms)
- [概率论与数理统计](https://github.com/TongjiCEIENotes/Probability-and-Statistics)

## 使用说明

各课程仓库通常包含：

- `main.tex`：笔记主文件
- `figures/`：图片、水印与其他资源
- 样式文件：用于统一排版
- `.gitignore`：忽略 LaTeX 编译产物

如需阅读 PDF 笔记，请优先查看对应仓库的 Release、README，或自行从 LaTeX 源码编译。
